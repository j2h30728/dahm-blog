# 햄스터 파비콘

2026년 11월 3일 사용자가 제공한 이미지의 오른쪽 아이보리색 햄스터 얼굴을 선택했다. 내장 `image_gen` 도구로 투명 배경 시안을 만들고 연한 갈색 윤곽을 보완했다. 사용자가 선택한 윤곽 시안의 투명 여백을 줄여 256×256 작업용 마스터 `hamster.png`로 보존했다. 내보내는 PNG는 64px이며, 브라우저 탭의 표시 크기는 브라우저가 결정한다.

- 아이보리색 털, 분홍색 귀·코와 원래의 보송한 질감을 유지한다.
- 귀·볼·턱의 실루엣에 연한 갈색 윤곽을 넣어 흰 배경에서도 형태가 보이게 한다.
- 정사각형 너비의 약 98%를 얼굴이 채우게 하되, 귀와 볼을 자르지 않는다. 이보다 크게 배치하려면 실루엣 일부를 자르거나 비율을 바꿔야 한다.
- 배경·배지·두꺼운 테두리를 추가하지 않고 투명 배경을 사용한다.
- 실제 16·32·48px 크기와 밝은/어두운 배경에서 표시를 확인한다.

`public/favicon.png`는 원본에서 축소한 64×64 PNG이며, `public/favicon.ico`에는 16×16·32×32·48×48 PNG 프레임이 들어 있다. `layout.tsx`의 `metadata.icons`가 두 파일을 가리킨다. 브라우저가 받는 파일에는 큰 원본 이미지를 포함하지 않는다.

선택한 1254px 윤곽 시안에서 `(left: 9, top: 33, width: 1211, height: 1211)` 범위의 투명 바깥 여백을 제거했다. 주요 실루엣(alpha 24 이상)의 경계는 `x: 17~1211, y: 114~1163`이어서 귀와 볼이 모두 포함된다. 원래 약 95.3%였던 가로 점유율을 약 98%로 늘린 배치다. 마스터에는 이미 이 배치가 반영되어 있으므로 재생성할 때 다시 자르지 않는다.

형식 변환은 기존 `packages/content-sync`의 Sharp를 사용하며 새 의존성을 추가하지 않았다. 저장소 루트에서 아래 명령으로 마스터에서 파비콘을 다시 만들 수 있다.

```sh
rtk proxy pnpm --filter @dahm-blog/blog exec node scripts/generate-favicon.mjs
```

`metadata.icons` URL의 `v=hamster-outline`은 이전 파비콘 캐시와 구분한다. 선택한 윤곽 시안의 생성 프롬프트는 [prompt.txt](./prompt.txt)에 기록한다.
