# OG 이미지 폰트

Pretendard 1.3.9의 정적 SemiBold WOFF를 사용한다. 빌드 중 다운로드하거나 운영체제 폰트에 의존하지 않는다. 제목·라벨·푸터는 크기와 색으로 위계를 구분한다.

- 원본: https://github.com/orioncactus/pretendard/tree/v1.3.9
- 파일: https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/packages/pretendard/dist/web/static/woff/Pretendard-SemiBold.woff
- 라이선스: SIL Open Font License 1.1, 동봉한 OFL.txt 참조
- PNG 생성 원본: scripts/lib/social-image.mjs
